## 🔍 Finding Documentation

### By Topic
- **Getting Started**: Check `/guides/setup/`
- **API Reference**: See `/core/DrSync_API_Documentation.md`
- **System Design**: Look in `/architecture/`
- **Specific Feature**: Browse `/features/[feature-name]/`
- **Task Reports**: Navigate to `/tasks/TASK-[number]/`

### By Phase
- **Phase 1**: See `/progress-reports/2025/PHASE_1_COMPLETE.md`
- **Phase 2**: Check task-specific reports in `/tasks/`
- **Phase 3**: Look for PHASE-3 reports in `/progress-reports/2025/`

## 📝 Documentation Standards

- Use clear, descriptive filenames
- Include date in filename for dated reports
- Update task tracking in `/core/DrSync_Task_Tracking.md`
- Archive old versions rather than deleting
